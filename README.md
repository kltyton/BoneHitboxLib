# BoneHitboxLib

Blank multi-loader Minecraft mod template for Fabric and NeoForge.

## Modules

- `common`: shared Minecraft-facing code.
- `fabric`: Fabric loader entrypoint.
- `neoforge`: NeoForge loader entrypoint.

## Commands

```powershell
.\gradlew.bat build
.\gradlew.bat :fabric:runClient
.\gradlew.bat :neoforge:runClient
```
